# Public dataset sources

These are the **original provider pages**. Dataset downloads are not mirrored in this repository.

| Dataset              | Official source                                               | What to download                                                                                             | Notes                                                                                                          |
| -------------------- | ------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------- |
| Visual Genome        | https://visualgenome.org/api/v0                               | Scene graphs, object/attribute/relationship annotations, image metadata; images from linked Stanford mirrors | Images and graph annotations are large. Verify version and use source licences.                                |
| SpokenCOCO (MIT SLS) | https://sls.csail.mit.edu/downloads/placesaudio/downloads.cgi | SpokenCOCO 600k spoken-caption audio package                                                                 | Images are not included; obtain the corresponding MS COCO image dataset separately.                            |
| MS COCO              | https://cocodataset.org/#download                             | Matching images, instance labels and annotations                                                             | Correctly pair original captions/image IDs and annotation versions; beware train2014 vs train2017 differences. |
| Spoken ObjectNet     | https://sls.csail.mit.edu/downloads/son/index.cgi             | SON spoken audio/caption metadata                                                                            | SON contains recorded speech, NOT ObjectNet images. Check licence/usage terms on provider page.                |
| ObjectNet            | https://objectnet.dev/download.html                           | ObjectNet high-resolution images                                                                             | ObjectNet requires attention to its border-removal and redistribution rules.                                   |
| Official SON code    | https://github.com/iapalm/Spoken-ObjectNet                    | Reference for native SON data matching and evaluation                                                        | This is the dataset authors' code, not this repository's ProKG code.                                           |
